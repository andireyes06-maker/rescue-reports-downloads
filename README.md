# Rescue Reports downloads

Public Android group-test builds. Download the APK from [Releases](https://github.com/andireyes06-maker/rescue-reports-downloads/releases).

The app uses the internet. Install updates over the existing app to retain data. Android may ask you to allow installation from your browser or file manager.

These are debug-signed test builds with the visible DEBUG ribbon disabled, not store-signed releases. No real emergency response is guaranteed by using this student project. No credentials or source code are distributed in this repository.
